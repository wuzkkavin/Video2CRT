# Video2CRT 使用者操作手冊

## 安裝

執行 `Video2CRT_0.1.0_x64-setup.exe`，使用預設的目前使用者安裝即可。安裝包已包含基本執行環境；不要另外用 winget 或系統 Python 重裝依賴。

## 轉檔

1. 貼上公開 YouTube URL，按「下一步」。
2. 選擇裁切、ASR 語言、字幕模式與輸出資料夾。
3. 按「開始轉檔」。開始按鈕會鎖定，避免同一工作重複啟動。
4. 進度頁完成下載、CRT 渲染、ASR、翻譯、字幕燒錄與封裝後，從完成頁開啟資料夾。

輸出資料夾會以影片標題命名；同名資料夾會加序號，不覆寫既有成果。主要交付檔案是 `final.mp4`，字幕檔是 `zh-Hant.srt`。

## 高品質模型

標準模型已隨安裝包提供。安裝程序在檔案複製完成後會詢問是否下載約 3.2 GB 的高品質模型；選擇略過即可直接使用標準模型。程式運行期間不會再跳出模型選擇視窗。

高品質模型會放在目前 Windows 使用者的 `%LOCALAPPDATA%\Video2CRT\models\large`，完成 manifest 驗證後才會啟用。安裝時下載失敗不會影響標準模型；重新執行安裝程式即可重試。

## 翻譯方式

- **本機端翻譯**：字幕文字留在本機。
- **本機端優先，失敗時使用雲端翻譯**：只有本機翻譯失敗且已設定 MiniMax API Key 才會傳送外語字幕。
- **純雲端翻譯**：需要先在設定中保存 API Key。

API Key 只保存於 Windows Credential Manager，程式不會把它寫入設定檔或輸出資料夾。

## 常見問題

| 現象 | 處理方式 |
| --- | --- |
| 安裝後提示找不到工具 | 重新執行安裝包；不要自行改 PATH。 |
| 安裝時模型下載失敗 | 檢查網路與磁碟空間，重新執行安裝程式；標準模型仍可使用。 |
| YouTube 要求驗證或回傳 429 | 程式只會對明確的 PO Token／Visitor Data／429 情況有限回退；仍失敗時換成公開且允許嵌入的影片。 |
| 畫面被裁切 | 回到選項頁輸入已確認的 `W:H:X:Y`，不要修改全域設定。 |
| 雲端翻譯沒有作用 | 確認設定頁顯示 API Key 已保存，或改用本機翻譯。 |
